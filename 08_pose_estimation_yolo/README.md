# 08 - Pose Estimation with YOLOv8-pose

`yolo_pose_estimation.py` runs YOLOv8-pose on the webcam, reads the body keypoints and classifies a few poses with simple geometric rules
(*Hands up*, *T pose*, *Standing*). Weights: `yolov8n-pose.pt`. Press `q` to quit.

```bash
python yolo_pose_estimation.py
```
