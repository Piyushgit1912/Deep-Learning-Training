# 06 - OpenCV Basics

| Script | What it does |
|---|---|
| `read_and_display_image.py` | load, resize and show an image (`image3.png`) |
| `read_resize_and_save_video.py` | read a video, display it and save `output.avi` (expects your own `video1.mp4`) |
| `webcam_capture_and_record.py` | show the webcam live and record it to `output.avi` |

Run the scripts from this folder. Press `1` to stop the video scripts.
