# 01 - Neural Network Fundamentals

Core building blocks of deep learning, implemented **from scratch with NumPy** so every formula is visible.

| Notebook | Topic |
|---|---|
| `01_single_neuron_and_forward_pass.ipynb` | weighted sum, activation, a layer, a tiny full network |
| `02_activation_functions.ipynb` | sigmoid, tanh, threshold, ReLU, Leaky ReLU, softmax (with plots) |
| `03_loss_functions.ipynb` | MAE, MSE, Huber, binary / categorical cross-entropy, hinge |
| `03b_categorical_cross_entropy_scratch.ipynb` | scratch notes on categorical cross-entropy |
| `04_gradient_descent.ipynb` | minimising x^2 and fitting a line with gradient descent |
| `05_optimizers.ipynb` | mini-batch GD, momentum, Nesterov, Adagrad (Adadelta placeholder) |
| `06_backpropagation_from_scratch_xor.ipynb` | a 2-3-1 network learns XOR via backpropagation + decision boundary |

**Requires:** numpy, matplotlib
